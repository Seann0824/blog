这个站没有用 UI 框架，也没有装 Tailwind。整套排版是一份手写的 CSS，加起来五百行左右。不是因为框架不好，而是博客这种页面数量极少、结构极稳定的场景，手写反而更快也更可控。

## 行宽

正文容器宽度定在 `44rem`，大约每行 35~40 个汉字。这是长文阅读比较舒服的区间：再宽眼睛要来回扫，再窄读起来会断气。

移动端靠 `padding` 收窄，不额外改字号——手机上 16px 是浏览器不会误解的值。

## 暗色模式

三种状态：跟随系统、强制亮、强制暗。`data-theme` 挂在 `html` 上，CSS 变量整体切换，避免组件级判断。

一个细节：主题脚本必须内联在 `<head>` 里同步执行，否则页面会先亮后暗闪一下。代价是几行无法缓存的内联 JS，这个交换划算。

## 字体

不引 Web Font。中文 Web Font 动辄几 MB，为了字形细节牺牲首屏不值得。用系统字体栈：

```css
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Hiragino Sans GB", "Noto Sans SC", sans-serif;
```

Mac 上落到苹方，Windows 上落到微软雅黑，安卓落到思源。都不难看。

## 要不要评论

暂时不要。个人博客的评论要么是广告，要么是三条"写得好"。想讨论的人会发邮件，或者去 GitHub 提 issue——这两个渠道的对话质量明显更高。

## 什么该省略

列表页不放摘要、不放封面图、不放阅读数。只放标题、年份和日期。信息密度低一点，扫读反而快。
